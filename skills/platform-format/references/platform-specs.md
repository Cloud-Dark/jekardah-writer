# Platform Specs

Reference limits and conventions. Treat numeric limits as the platform's hard technical ceiling, not a stylistic target — a good caption is usually well under the ceiling.

## Instagram (feed caption / carousel)

- Caption hard limit: 2,200 characters; only ~125 characters show before "more" — front-load the hook and payoff-relevant word within that window.
- Hashtags: place at the end, after a line break or two, or in the first comment if the account's convention does that. 3-8 relevant tags beats 30 generic ones.
- Carousel: one clear idea per slide, slide 1 repeats the hook, last slide carries the CTA.
- Line breaks: short paragraphs (1-3 lines), blank line between beats — dense text reduces read-through.

## X / Twitter (single post or thread)

- Single post limit: 280 characters (standard tier).
- Thread: first tweet must work as a stand-alone hook — it is often the only part shown in previews. Number tweets (`1/`, `2/`) only if the account's convention uses it; otherwise let each tweet flow with a short connective.
- One idea per tweet. Split at natural sense-breaks, not mid-sentence.
- CTA and link go in the last tweet, not buried mid-thread.

## LinkedIn

- Post is fully visible up to roughly 3 lines before "see more" (about 210 characters) — put the hook there.
- Short paragraphs (1-2 sentences), generous line breaks — dense paragraphs read as corporate filler on this platform.
- Professional register by default; avoid hashtag stuffing — 3-5 relevant tags at the end is enough.
- CTA is usually a question or explicit ask in the last 1-2 lines.

## TikTok / Reels / Shorts script

- Structure as a beat list: `[visual cue] — [spoken line]`.
- Hook must land in the first 1-3 seconds (roughly the first line) — no slow setup.
- Keep spoken lines short enough to say naturally in the beat's duration; do not write paragraph-length lines.
- End on a clear CTA beat (follow, comment, link in bio) as its own beat, not folded into the last content line.

## Newsletter / email

- Subject line is a separate deliverable — do not reuse the body's opening line verbatim; keep it short enough to not truncate in a typical inbox preview (~50-60 characters is a safe target, not a hard limit).
- Preheader (if used) should extend the subject line's promise, not repeat it.
- Body can run long-form; still favor short paragraphs and clear section breaks over dense blocks.
- One primary CTA; secondary CTAs (if any) clearly subordinate.

## Generic long-form (blog, article, script for reading aloud)

- No platform character ceiling — structure by section/heading instead of unit-splitting.
- Preserve the source's heading/section structure unless restructuring is explicitly in scope.
- Favor scannable structure (headings, short paragraphs, occasional lists) without turning prose into a slide deck.
